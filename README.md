## Projects

### [FoodMed Check: Explainable Drug–Food Interaction Prediction](https://github.com/saitej-1/foodmed-check)

A full-stack platform that predicts whether a drug and a food compound are likely to interact, and explains each prediction.

- RDKit molecular descriptors and fingerprints, a 4-stage feature selection pipeline, and a 3-class XGBoost classifier
- SHAP explanations served through a FastAPI backend, with PostgreSQL for data and a Next.js frontend
- Work in progress: the README lists the project status and known limitations

`Python` `XGBoost` `RDKit` `SHAP` `FastAPI` `PostgreSQL` `Next.js`

### [Aegis AI: Food and Drug Interaction Profiler](https://github.com/saitej-1/drug-food-intraction-platfrom)

A browser app that predicts whether a food and a medicine are likely to interact (safe, moderate warning, or severe danger).

- Neural network written from scratch in JavaScript (forward pass, backpropagation and training loop, no ML library), trained live in the browser
- Dataset of 54 foods and 49 drugs (2,646 pairs) encoded as pharmacological features
- SMILES parser and 3D ball-and-stick molecule viewer built with Three.js

`React` `Vite` `Three.js` `JavaScript` `Python`
